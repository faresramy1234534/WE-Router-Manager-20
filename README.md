# إدارة راوتر WE — مشروع أندرويد

تطبيق أندرويد بواجهة عربية لفتح صفحة إدارة راوتر WE/TE Data من داخل التطبيق، مع اكتشاف عنوان البوابة عبر Wi‑Fi، إدخال العنوان يدويًا، حفظ آخر عنوان، وأزرار للعناوين الشائعة.

## البناء والتشغيل
1. ثبّت Android Studio بإصدار حديث يدعم Android Gradle Plugin 8.7.3.
2. افتح مجلد `WE_Router_Manager` في Android Studio.
3. اسمح بمزامنة Gradle وثبّت Android SDK Platform 35 عند الطلب.
4. وصّل هاتف أندرويد، ثم اختر **Run**. لإنشاء APK اختر **Build > Build APK(s)**.

## ملاحظات مهمة
- هذا المشروع هو واجهة وصول لصفحة الراوتر الأصلية؛ لا يتجاوز كلمة المرور ولا يغيّر إعدادات الراوتر تلقائيًا.
- يجب أن يكون الهاتف متصلًا بشبكة الراوتر المحلية. بعض أجهزة WE تستخدم `192.168.1.1` أو `192.168.0.1`، لكن العنوان قد يختلف.
- عناصر مثل تغيير اسم الشبكة وكلمة المرور، مشاهدة الأجهزة، أو إعدادات الحماية تختلف باختلاف موديل الراوتر والبرنامج الثابت، وتظهر داخل صفحة الإدارة الرسمية بعد تسجيل الدخول.
- يدعم المشروع صفحات الإدارة المحلية عبر HTTP لأن كثيرًا من أجهزة الراوتر تستخدمها. استخدم التطبيق على شبكة موثوقة فقط، ولا تُدخل بيانات الدخول في عناوين أو صفحات غير معروفة.
- لا يحتوي المشروع على خدمة خلفية أو تحليلات أو تخزين لكلمة مرور الراوتر.

## التقنية
Kotlin، Android WebView، minSdk 23، targetSdk 28.

## إنشاء APK تلقائيًا بدون Android Studio (عن طريق GitHub)
إذا لم يكن Android Studio مثبتًا، يحتوي المشروع على سير عمل جاهز للبناء السحابي:
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد** إلى المستودع (بحيث يكون `app` و`build.gradle` و`.github` في جذر المستودع).
3. افتح تبويب **Actions**، ثم اختر **Build Android APK** واضغط **Run workflow** إذا لم يبدأ البناء تلقائيًا.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
5. نزّل `WE-Router-Manager-APK.zip`، وفك ضغطه لتحصل على `app-debug.apk`.

هذا APK تجريبي (debug) للتثبيت والاختبار، وليس إصدارًا منشورًا على متجر Google Play. لم يتم التحقق من بناء APK داخل بيئة إعداد المشروع الحالية.
